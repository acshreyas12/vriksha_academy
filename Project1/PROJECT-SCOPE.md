# Vriksha Academy — One Page Project Understanding

## What I understood
Vriksha Academy is a learning and practical workshop platform for D2C founders. It explains how modern AI systems work and gives founders a glimpse of how to structure an AI team using Business Brain/CLAUDE.md, Skills, Agents, Sub-agents, Connectors/MCPs, workflows, retrieval, guardrails and human approval.

## Objective
Build a professional website that explains **what founders will learn, how the learning is structured, what they can walk away with, and which training format they can choose**. The site should create interest and enquiries rather than publish the complete workshop implementation.

## Public website
**Home:** Academy introduction, hero, outcomes, AI team idea, four building blocks, founder ground rules and CTA.

**What You'll Learn:** Short, founder-friendly glimpse of the 24 concepts: Model/LLM, Tokens, Prompts, Context, Agent Loop, Skills, Tools, Commands, Memory, Agents, Sub-agents, Workflows, Orchestrations, MCPs, Connectors, Artifacts, RAG, Structured Output, Evals, Guardrails, Human-in-the-loop, Cost/Speed/Observability and AI Teammate end-to-end.

**Programs:** Training categories: Group Workshop/Webinar, One-to-One Founder/CEO, Dedicated Company Session and On-site Training. Exact pricing is not invented; it is shown as Price on enquiry until confirmed.

**Contact:** Founder/company enquiry form.

## Logged-in area
A simple dashboard showing learning progress, concept modules, the workshop map and resources. It is a learning interface, not the actual AI product.

## Learning journey shown
**Business Brain → Skills → Connectors → Agents → Captain → 90-Day Roadmap**

The website gives a glimpse of these topics; the detailed prompts, CLAUDE.md/SKILL.md recipes, connector setup and advanced implementation remain part of the actual training.

## Technology
React + Vite frontend, Java + Spring Boot REST backend, MySQL database.

## Future possibilities
Admin panel, payments, certificates, scheduling, course management, live AI APIs, real connectors/MCPs, AI-agent execution, analytics and notifications can be added later after confirmed requirements.
